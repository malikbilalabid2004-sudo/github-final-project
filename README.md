# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery Shopping Application

## Description
Paradise Nursery is an online plant shopping application built with React and Redux.

The application allows users to:
- Browse different categories of houseplants
- View plant images, names, descriptions, and prices
- Add plants to the shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cost of their selected plants
- Continue shopping or proceed to checkout

## Technologies Used
- React
- Redux Toolkit
- JavaScript
- HTML
- CSS
