# Simple Interest Calculator

This repository contains a Simple Interest Calculator that calculates simple interest based on user-provided values.

## Description

The Simple Interest Calculator is a Bash-based calculator that computes simple interest using the principal amount, annual rate of interest, and time period in years.

## Input

The calculator accepts the following user inputs:

- `p` - Principal amount
- `r` - Annual rate of interest
- `t` - Time period in years

## Formula

The simple interest is calculated using:

**Simple Interest = (Principal × Rate × Time) / 100**

or:

**SI = (P × R × T) / 100**

## Output

The calculator displays the calculated simple interest based on the values entered by the user.

## Example

If:

- Principal = 1000
- Rate = 5
- Time = 2 years

Then:

**Simple Interest = (1000 × 5 × 2) / 100 = 100**

## How to Run

Run the Bash script using:

```bash
bash simple-interest.sh
